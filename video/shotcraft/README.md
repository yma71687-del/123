# ShotCraft source used by NEXUS

Upstream: https://github.com/Vincentwei1021/video-shotcraft

Pinned commit: `1266a3ec4831289c4d893d42dd5102723658039a`.

The code is distributed under the included [Apache-2.0 license](LICENSE).
[ORIGIN.json](ORIGIN.json) records the original source paths and hashes.

`FlyingWords` is modified for NEXUS: brand, title, accent, keywords and source
duration are props; the upstream demonstration logo is removed. `Look` and
`Polish` are formatted copies. Original comments are retained.

No upstream product screenshots, music or sound effects are included. NEXUS's
other two studio recipes are implemented separately in `video/studio/Film.tsx`.
This integration does not install or claim support for the entire upstream
Workbench, shot catalog or AI services.
