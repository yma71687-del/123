本机日期：2026-10-24。实际运行代码、浏览器、FFmpeg 与独立 Docker 容器，不替换正常路径上的媒体渲染器。

## 本批修复

API 容器作为 root 上传素材，原子写入的素材 JSON 清单权限为 0600；渲染容器作为 node 读取同一只读卷，提交含产品图的渲染任务会返回 EACCES。界面预览经过 API，因而无法暴露这一故障。

先在真实四服务容器链路复现 HTTP 400/EACCES，再只将新上传的素材清单设置为 0644。用户工程仍为 0600，未修改容器身份、只读卷或其他项目权限。新增权限契约测试，以及实际上传产品图、渲染 MP4 后检查对应橙色像素的容器回归。历史实例的数据未自动修改或迁移。
