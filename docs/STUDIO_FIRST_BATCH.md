# 新创作工作台：第一批可验证交付

2026-11-08。本批是 0.6 开发预览，完成统一工程、三个镜头、基础多轨编辑和真实带声输出；不是完整 AI 影视广告平台或腾讯云上线公告。

## 看实际结果

- [9 秒带声 MP4 演示](../deliverables/NEXUS-STUDIO-FIRST-BATCH-720p.mp4?raw=true)：原创矢量产品、文字纵深隧道、代码构造的三层展示、字幕、独立配乐和音效。
- [实际桌面界面](../deliverables/NEXUS-STUDIO-FIRST-BATCH-DESKTOP.png) ／ [手机界面](../deliverables/NEXUS-STUDIO-FIRST-BATCH-MOBILE.png)。桌面面板独立滚动，时间线与预览共处一个工作区。
- [可导入的演示工程](../examples/studio-first-batch-sample.json) ／ [媒体参数与 SHA256](../deliverables/NEXUS-STUDIO-FIRST-BATCH-VERIFICATION.json)。演示工程只使用内置原创图形和声音，不依赖他人产品图。

演示的“图层展示”没有执行 AI 图片拆层。用户上传的 PNG／JPEG／WebP 可以用于产品主视觉；分别上传的图片或透明 PNG 可以成为图层展示的独立平面。普通照片不会被自动识别成原始图层。

## 本批实际能力

| 功能 | 行为与边界 |
| --- | --- |
| 统一工程 | 独立 `nexus-project-ir` v1，严格 JSON 校验；首批固定 1920×1080、30fps、1–30 秒 |
| 三个镜头 | 产品主视觉、适配 ShotCraft 的文字纵深隧道、图片图层展示；品牌、标题、主色、关键词及图片可改 |
| 多轨编辑 | 镜头叠放、拖动、方向键微调、裁入／裁短、分割、复制、删除、显隐与提高图层；分割保留源帧和关键帧 |
| 属性关键帧 | 每个镜头的 x、y、缩放、不透明度；可设置、定位、删除，实际影响预览和服务端渲染 |
| 声音与字幕 | 独立配乐／音效片段，上传自有音频、调整开始／持续时间、音量与静音；复用 SRT／VTT 和字幕编辑器，实际烧录 |
| 撤销与输入 | 编辑命令可撤销／重做，拖动只计一次；文本和数值输入允许中间编辑状态，不把半截数字写入工程 |
| 项目保存 | 服务端多项目、另存新项目、100 个以内历史版本、旧版本载入草稿、JSON 备份与导入；旧 revision 覆盖被拒绝 |
| 旧工程导入 | 旧广告导入成新草稿，保留原视觉配置，声音／字幕独立映射；旧广告文件不改写 |
| 真实导出 | 720p／1080p H.264 MP4＋AAC；与旧广告共用持久化渲染队列，单次只处理一条任务，支持取消和下载 |

首批最多 24 个画面片段、24 个声音片段、每镜头 6 张图片和 64 个关键帧。图片图层镜头显示所有引用图片；产品主视觉只显示第一张。帧率和画幅的扩展、波形、音量包络、相机／旋转关键帧、自由视频轨不在本批完成范围。

项目库先采用单实例的私有文件和原子替换，包含版本冲突保护；**尚未迁移 PostgreSQL，也没有多用户账户与所有者隔离**。服务器重启后可读回工程和已完成任务；中断中的渲染按已有规则标记失败，不会假称自动续渲。

## 本机启动与操作

运行条件沿用项目：Node.js 24、Python 3.12+、Chromium、FFmpeg。已配置开发环境可直接运行：

```sh
npm run build
.venv/bin/python tools/launch_studio.py
```

首次准备依赖可参照根 README 的锁定版本安装方式。启动器仅监听本机，默认界面为 `http://127.0.0.1:43160/#studio`；若端口已占用，使用 `--port 0`，以终端实际输出为准。它同时启动 API 和 worker，Ctrl+C 只停止自己创建的进程。这里是开发地址，不是用户腾讯云的公网地址。

数据默认保存在 `.local-data/studio-development`，不读取或覆盖 v053、v054 或生产 live 目录。

操作顺序：

1. 左侧上传产品图，选择“产品主视觉”，点击自己的图片；修改右侧品牌、标题与主色。
2. 点击或拖入其他镜头到时间线，移动片段并调整开始／持续帧；通过播放头定位后分割。
3. 选中镜头，在播放头设置属性关键帧；选中声音片段调整音量、静音和落点。
4. 保存工程并重开；需要备份时导出 JSON。JSON 不包含用户媒体文件，请保留原件和服务器素材。
5. 选择分辨率并导出，任务完成后下载 MP4。每次导出使用提交时的工程快照。

旧界面通过右下角“新版创作工作台”入口进入，也可直接使用 `/#studio`。历史本机广告试用包仍为 0.5.4，不包含本批新工作台。

## 自动化验证

```sh
npm run test:unit
.venv/bin/python -m unittest discover -s tests/studio -v
```

新增的 Node 测试覆盖工程约束、关键帧插值、分割源时间、旧工程导入，以及并发保存、历史版本、损坏文件保留。新增集成测试使用真实 API、Chromium、图片上传和 Remotion 编码，覆盖浏览器编辑、鼠标拖动、撤销、版本冲突、刷新重开、JSON 下载、UI 提交／下载 MP4，以及重启后的持久化。

6 秒验收 MP4 使用测试上传的真实 PNG，检查 H.264／AAC、720p、时长、产品颜色像素、字幕颜色像素、三段画面变化和非静音音轨。另有上方 9 秒的自包含演示片。详细测试范围见 [测试记录](TEST_REPORT_STUDIO_FIRST_BATCH.md)。

## 未完成与部署事实

AI 图片自动分层／修边、图生视频、LLM 分镜编排、自动转写／配音、更多镜头、精确 3D 和电影质感逐镜验收仍需后续开发。本批没有给这些能力提供假按钮。

本次未连接或修改腾讯云生产环境，未新增已验证的腾讯云公网网址或固定域名。后续已新增并实测 [0.6.0 独立安装入口](../deploy/STUDIO.md)，不要使用旧 0.5.4 命令部署新版。完整镜像、登录、安装验收与保护检查见 [0.6.0 部署记录](TEST_REPORT_STUDIO_0.6.0_DEPLOYMENT.md)。服务器现场的公网结果仍需实际核验。

ShotCraft 仅移植了本批所需的文字隧道及两个视觉工具文件，保留 Apache-2.0 许可、固定来源和修改记录；没有整体安装上游全部 Skills、镜头库、音频或 Workbench。原 0.5.4 广告试用包保持字节不变；0.4 基础预览因入口构建代码调整而重新生成，功能范围不变，另有断网浏览器回归。
