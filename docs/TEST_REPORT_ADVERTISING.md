## 已交付样片

`NEXUS-MOTION-SHOWCASE-1080p.mp4` 为工作台实际提交并完成的三段广告：卡片与标题 → HUD 指标 → 品牌片尾。画面和声音由同一次 Remotion 渲染输出，未用外部剪辑伪装为系统功能。

- 1920×1080，30 FPS，约 15.019 秒，H.264 视频与 AAC 音频。
- 修正标题排版后的任务实测耗时 53.293 秒。
- FFmpeg 检测平均音量约 -31.9 dB、峰值 -8.8 dB；不是无声音轨，没有削波。
- 演示图表使用样例指标，示例配乐与音效由 `tools/generate_ad_audio.py` 原创生成。
- 配套 `NEXUS-MOTION-PROJECT.json` 不含服务器私有素材，可导入广告工作台重开。

完整来源视频不随代码分发。第二个参考文件超过工具 32 MB 读取限制，尚未分析，不在本批“已复现”范围。

## 容器与部署边界

API、Web、Node/Chromium 镜像均实际构建。初次本地打包因 Docker `vfs` 反复复制大层导致磁盘不足；调整渲染镜像的安装顺序并只清理该次明确 ID 的构建缓存后，构建与完整 Docker 测试通过。未使用全局 prune，没有删除其他应用的镜像、容器或卷。

补充发现：默认 Docker 客户端代理配置下，旧网关回归出现内部转发 HTTP 403；显式配置内部服务的 `NO_PROXY` 后，使用相同默认客户端配置重新运行的 8 项部署测试通过。新版部署配置也固定对内部服务绕过出口代理。

服务器资源、DNS、镜像下载、HTTPS 公网访问、已有域名路由和原业务健康尚需在目标腾讯云环境实际验收。源码可部署不等于已经上线。原固定 0.4 安装器继续保留，不能用于宣称本批广告功能已发布。
