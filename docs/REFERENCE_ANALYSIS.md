# 参考视频解析：已实现与使用方法

本批增加广告工作台的真实参考片解析入口。它用于核对画面、字幕、声音和时间点，随后才能把参考效果实现为可编辑模板。抽帧不等同于理解视频，OCR 不等同于语音识别。

## 在工作台使用

部署包含本批代码的版本后，打开实际站点的 `/#advertising`，在“参考视频解析”点击“上传参考视频”。

1. 上传本机 MP4 / MOV / WebM / MKV / AVI / TS，最大 **90 MiB**、最长 **15 分钟**、最高 **1920×1080（含竖版）**。
2. 上传时显示真实传输进度，服务端解析时显示任务进度。列表可刷新恢复；失败显示原因。
3. 查看最多 48 张带时间点的均匀采样画面，点击图片打开大图。最多 12 张画面进行中英文 OCR，识别出的文字显示在相应截图下。
4. 有音轨时，真实提取第一条音轨为单声道 16 kHz WAV，可试听和下载。文字型内嵌字幕可提取为 WebVTT。
5. 下载解析 JSON，其中包含时长、尺寸、帧率、编码、音轨、采样时间、OCR 文字及完成状态。删除记录会同时删除该次截图、音轨和报告，不删除广告工程。

0.5.2 增加“将内嵌字幕送入广告”：提取成功的 WebVTT 可送入[字幕轨](CAPTIONS.md)，先核对截取范围和预览，再应用到广告。画面 OCR 文字和音轨提取不会冒充语音识别字幕。

画面中的烧录字幕属于 OCR 范围，可能识别错误；不能将它作为校对过的逐字稿。图片型字幕暂不转换。**尚未接入语音转写、自动语义分镜、自动技能识别或参考片一键复刻**，这些不会显示为已完成。

聊天附件工具仍有单文件 32 MiB 的传输上限，工作台上传接口的 90 MiB 上限无法让助手直接读取当前超限附件。第二个文件仍需压缩至 32 MiB 以内或分段重新提供，才能由助手逐项核对；工作台也尚未在腾讯云上线。

## 已在第一个参考文件实际运行

在用户已可读取的第一份文件上运行同一个解析引擎，实测：313.7 秒、1280×720、30 FPS、H.264、**没有音轨**。成功生成 48 张采样截图和中英文 OCR 报告；音频与字幕下载项为空，转写状态为 `no-audio`。

OCR 只能辅助定位：例如约 01:51 可读出“灰色科技感背景、透视网格地面、网格线持续向远处移动、轻微发光、远处渐隐”等画面要求；约 04:08 可定位 ProRes / PNG 导出界面。文字错误需结合原截图修正。人工核对的详细效果清单见 [参考片拆解](REFERENCE_VIDEO_BREAKDOWN.md)。

用户原片、截图、OCR 原始报告均保留在本地私有目录，**不发布到 GitHub 或源码包**。测试使用独立生成的 `NEXUS TEST` 画面和合成音频。

## 本地文件解析

已有服务器本地文件时，可直接运行，无需经过聊天附件传输。输出目录必须是新目录，以免覆盖已有文件。

```bash
.venv/bin/python tools/analyze_reference.py /你的本地参考视频.mp4 --output /tmp/nexus-reference-review
```

需要 FFmpeg、FFprobe、Tesseract 和中英文语言包。新版 API Docker 镜像实际安装这些组件。宿主机手动运行时可用 `tesseract --list-langs` 检查 `chi_sim` 与 `eng`；缺少 OCR 时仍可抽帧，但报告会明确警告，缺少 FFmpeg 时拒绝解析。

## 资源与接口边界

- 同时只接受一条上传／解析；最多 10 条记录。单条解析总超时 180 秒，解码器和 OCR 使用单线程。
- 参考片目录预留上传和派生文件空间，累计预算 512 MiB；不足 1 GiB 加上传预留空间时拒绝新上传。原文件在成功或失败后删除，保留可审核的派生结果。服务重启会将未完成任务标为失败，避免永久“处理中”。
- 数据存于该 NEXUS 实例自己的 `/data/references`，文件权限 600、目录 700。沿用网关登录保护、内部 API 不对公网暴露。不是多用户隔离存储。
- 仅解析上传的本地容器格式，FFmpeg 协议及 demuxer 使用白名单；不接受媒体 URL、播放列表、主机路径或任意输出文件名。
- `/api/references` 接收流式原始文件请求；Nginx 对该入口关闭请求缓冲，单独限制 90 MiB 和超时，超限／空文件／上传断开会清理临时文件。
- `GET /api/references/capabilities` 显示实际解码器、OCR 语言和语音识别状态。下载只允许已完成记录中的 JPEG、WAV、VTT 和解析 JSON，不提供源文件和内部任务文件。

本批没有连接腾讯云或修改其他业务。发布包和部署命令必须使用包含本批源码的版本；先前固定 0.5.0 的命令不会自动得到此入口。
