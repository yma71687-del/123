# 0.5.4：可操作的广告制作界面

本版调整现有真实功能的操作流程，增加分镜导航及逐张图片排序／移除，保留已有 API、工程格式及真实媒体渲染。没有新增 AI 模型、自由多轨关键帧或全部参考片效果。

## 从画面开始操作

1. 在左侧效果库悬停或用键盘聚焦，观看静音动画；点击将模板用于当前工程。四套封面由真实 Remotion 合成渲染，悬停使用同一组件。仅挂载一个当前悬停的动画预览；系统开启“减少动态效果”时保留静态封面。
2. 上传产品图／音乐。素材列表中的箭头可前移图片，叉号仅移除工程引用，原素材保留。右侧“品牌”面板修改文案和颜色。
3. 选择右侧“动画”面板调整时长、旋转、半径、卡片名称与 HUD 数值；中间大画面直接反映参数。组合广告有三段分镜按钮，点击可定位实际播放游标。分镜结构仍由模板决定，尚不能自由增删或拖动片段。
4. 下方“字幕”和“声音”分别编辑字幕时间／正文、背景音乐及独立音效。“参考解析”保留上传、抽帧、OCR、音轨及内嵌字幕入口，已提取字幕可送入字幕编辑器。
5. 右侧“导出”设置尺寸和格式，点击“生成这条广告”；顶部也保留渲染入口。任务面板显示真实排队、进度、失败原因和下载链接。批量标题使用相同包装生成独立任务。

顶部五个步骤用于导航，切换不会清空字幕、声音或未保存参数。工具和参数标签支持方向键、Home／End；手机端优先显示主预览，步骤按钮可定位操作区域，导出设置中也能直接开始渲染。

## 保存与示范

顶部保存状态根据当前工程与最近一次成功读写的云端快照比较，参数变化后标记未保存。服务端保存成功才显示一致；提交保存期间继续修改的内容仍保持未保存状态。

“载入带声字幕示范”载入现有 15 秒完整工程，不自动保存云端。恢复入口位于“工程文件”菜单，原参数和输出设置在浏览器允许存储时可跨刷新恢复。导入／导出 JSON 仍可用；媒体引用需要对应服务器仍有原文件。

## 验证

- TypeScript、生产构建、格式检查及 21 项 Node 单元测试通过。
- 11 项实际广告浏览器／媒体测试通过；补测新版输出确认入口及完整工作流 2 项通过，包含真正提交、下载和解码字幕／声音成片。
- 新增完整工作流测试确认：悬停画面真实变化且不写云端／不创建渲染任务；分镜定位到 5／10 秒；键盘切换标签；保存状态反馈；产品图排序和移除后云端保存；减少动态效果；手机无横向溢出。
- 参考片 10 项回归通过；离线基础 3D ZIP 2 项通过。离线包仍仅包含原基础 3D 能力，不能用于广告云端渲染。
- 容器链路最终结果见 [本批完整验收](TEST_REPORT_WORKSPACE.md)。截图来自本机实际浏览器，不是腾讯云已上线的证据。

## 发布限制

0.5.4 使用独立部署目录、Docker 项目和端口，保留用户控制台中已运行的 0.5.3。没有自动迁移旧工程／素材、覆盖旧入口或完成固定域名切换。0.5.3 若仅需继续公网发布，可使用固定的 0.5.3.2 恢复命令；该操作不会更新到新界面。

当前会话未获得腾讯云远程控制连接，0.5.4 未在目标服务器执行验收。AI 分层、语音识别、自动语义剪辑和自由对象／相机多轨编辑仍未完成。

## 可操作的单文件试用包

[下载广告操作界面](../deliverables/NEXUS-AD-WORKSPACE-0.5.4-interactive.zip?raw=true)，解压后用桌面 Chrome／Edge 打开“打开广告工作台.html”。这是实际广告组件与编辑控件的独立构建，内置封面和配乐，不调用远程 CDN 或 API。

已在精确 ZIP 的 HTML 上断网验证：编辑、真实声音播放、图片／音乐导入、字幕编辑、IndexedDB 保存、关闭浏览器后重新打开恢复、JSON 下载，以及存储失败可见。视频渲染入口保持禁用，参考解析显示未连接。当前环境禁止 file:// 导航，测试用静态宿主加载同一文件后断网，不把该结果表述为已在用户 Windows 上直接双击验收。
