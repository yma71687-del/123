# 第一批审计与修复

基线：`b29038057282f6bc8c3f5afa045fcdff6c900b0a`。范围为本地隔离开发环境，不包含腾讯云生产浏览器诊断或部署。

## 已复现的根因

1. **3D 初始化依赖外部 CDN，却未传播就绪状态。** 阻断 jsDelivr 后，`THREE` 不存在，初始化失败；按钮仍可点，切换预设会读到未初始化的 `scene.fog`。模式切换和云端保存仍能响应，因此“全部事件都没绑定”不是准确诊断。同版本 Three.js 通过诊断夹具提供后，渲染恢复。现在使用 npm 精确版本和 integrity 锁文件构建同源 bundle，保留 MIT 许可；无外部加载请求。
2. **数据模型只写素材引用，恢复没有重建对象。** 原版导入图片并保存后，服务器 JSON 有 1 个素材；刷新时 `imageObjects=0`、`assetMeta=0`。再次保存还会丢掉引用。标题平面从未序列化。现在用对象记录、云端 asset ID 和版本边界恢复真实 mesh；新建也会释放旧纹理、几何与音频。
3. **动画由墙钟增量驱动，不受暂停或定位约束。** 原版 `playing=false` 时画面仍变化。现在旋转、星空、预设和关键帧均由工程时间计算，种子固定；同一时间点可重复渲染。
4. **音效不是按时间轴事件触发。** 原版设置 cue=5 秒，在工程约 0.15 秒时音频已播放约 0.1 秒。现在在事件时间窗内同步音频，并支持明确取消选择；旧工程缺少 audio ID 和显式 `null` 的含义分开处理。
5. **上传失败被吞掉，回退本地 URL 后仍像成功。** 原版先添加素材行，再尝试云端上传，失败也继续显示图片，形成不可恢复的成功假象。现在失败有可见原因，不生成“云端已保存”的伪记录。
6. **新手模式隐藏了反馈区。** 操作失败提示本来被隐藏。现在顶部状态栏始终可见，错误使用 alert；加载／上传期间阻止冲突编辑。
7. **CSP 兼容性风险。** 原版事件与核心脚本均内联，后置“绑定修复器”也在同一内联脚本里，因此严格脚本策略会一起拦截。不能据此断言线上确有 CSP 拦截，因为尚未检查线上响应头。新版本在实际 Nginx 和测试服务的 `script-src 'self'` 下通过测试，无需放宽到 `unsafe-eval`。样式仍使用内联 style 属性，故仅 style 策略保留 `unsafe-inline`，不宣称完全移除内联样式。

原版观测值见 [baseline.json](evidence/baseline.json)。复现时使用 `git show <基线>:frontend/index.html` 和同提交 API 放入临时目录，数据也放入临时目录；没有运行旧安装／更新脚本。CDN 成功夹具仅用于区分网络与业务缺陷，不是新版本的生产依赖或通过测试的捷径。

## 验证门槛

- Node 单元测试：工程兼容、非法值、引用规范化、显式取消音频、关键帧排序。
- API：保存／读取、图片标题记录、Unicode 元数据、损坏数据不覆盖、并发写、磁盘错误、上传限制、引用和时间范围。
- Playwright：阻止外部请求的本地依赖；四预设真实像素不同；新手／专业模式；暂停／关键帧定位；鼠标拖动时间轴；真实文件选择器；上传保存刷新、JSON 重开、新建清空；故障注入；音频时间与音量；浏览器备份；真实无声 WebM 与手机布局。
- Compose：使用唯一临时项目，从真实 Nginx 访问 API 和静态脚本，验证严格脚本 CSP、WebGL、上传及保存重载；不启动生产 gate/tunnel。

故障注入分别阻断本地 renderer、让 WebGL 创建失败、让上传／保存返回错误。正常路径使用实际 FastAPI、WebGL、图片解码、媒体播放和下载，不以 mock 替代实际功能。

## 本批边界与下一步

这不是 React/TypeScript 整体重写。先外置代码、建立可测 v3 契约，保持旧工程可读；之后在既有回归测试保护下迁移组件和 typed project schema。

下一批依序交付：

1. React + TypeScript、对象树、选择／拖动／变换、撤销重做；四套真实不同几何与镜头的横版参数化场景。
2. 对象与相机多轨关键帧；独立音频事件、替换、增益、静音和波形；确定性时间轴和工程版本迁移。
3. 使用同一工程生成带音轨的成片，验收分辨率、时长、画面与音轨。当前无声画布记录不能替代此项。
4. 单独接入并基准测试分割／深度模型、GPU 渲染和之后的 Agent 工作流；评估共享主机资源，避免影响其他服务。
