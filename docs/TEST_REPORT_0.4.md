# 第二批验收：React／TypeScript 与对象编辑

日期：2026-10-23。基于第一批提交 `eea1357`，分支 `codex/editor-object-workflow`。本记录只代表隔离环境验证，不代表腾讯云生产部署或抖音样片视觉验收。

## 验收目标

对象可以添加、选择、移动／旋转／缩放、改材质参数、复制／删除，再撤销／重做，保存并刷新恢复。四个模板必须创建不同几何。迁移到 React + TypeScript 后，第一批交互、持久化、音效及预览下载不能退化。

本地结果：**9/9 单元、14/14 API、14/14 浏览器测试通过**，生产构建、格式、依赖一致性和隔离容器验证通过。npm audit 在验收时报告 0 条已知漏洞；这不代表完整安全审计。未验证远端 GitHub Actions 状态。

| 验证 | 覆盖 |
| --- | --- |
| npm 锁文件安装、TypeScript 严格检查、Vite 生产构建、Prettier | 可重建的模块化 React 界面与独立延迟加载的 Three.js bundle |
| 9 项 Node 测试 | v3→v4 迁移、引用和变换校验、撤销／重做、拖动事务、取消、历史容量、重做分支失效 |
| 14 项 API 测试 | 第一批 11 项＋v4 对象恢复／非法写入保护、v3 读取不改写原始字节、旧 v3 客户端拒绝覆盖新 v4 工程 |
| 14 项 Chromium／WebGL 测试 | 第一批 10 项＋对象变换／材质／隐藏保存恢复、复制删除及历史、实际轴柄拖动、几何差异与非法字段恢复 |
| ffprobe | 真实下载的 WebM 含视频、无音轨、时长超过 4 秒 |
| 两个 Docker 镜像与唯一临时 Compose 项目 | 实际 Nginx 下 CSP、渲染、素材上传、工程保存／重载 |

浏览器使用实际软件 WebGL；轴柄拖动测试先读取实际画布中的红色 X 轴像素，再用鼠标拖动，检查位置变化、一次撤销恢复到零、重做及 API 保存值。没有通过修改内部工程状态来冒充拖动。数值旋转、缩放、透明度、可见性也经保存与刷新检查。

证据由测试生成：`.test-results/object-editor-desktop.png`、`editor-desktop.png`、`editor-mobile.png`、`webgl-fallback.png`、`silent-preview.webm`。CI 配置上传 artifact，尚未把远端 Actions 状态算作本地通过结果。

## 能力边界

- 自由变换适用于新增的图片、标题和 3 种 3D 基元；模板环境装饰尚不能逐项选择。
- 当前仅有场景主体颜色／尺寸关键帧和一个主音效事件；对象／相机多轨与最终带音轨成片尚未完成。
- 历史只在当前编辑会话保存；加载、新建、JSON 导入会清空历史。
- 新工程版本为 4；读 v3 不写盘，明确保存后会写 v4。旧版 0.3.1 不能打开新工程，回滚需配套备份。
- 两条抖音短链均返回代理 403；未看到参考视频、未核实其中的开源 Skills，未宣称已复刻或安装。
- 没有连接或修改生产，没有检查 GrowAgent／Geo Engine 的线上健康。
