广告回归正常路径运行真实 Player、浏览器、Remotion、音频解码和 FFmpeg。覆盖已有预览、素材、保存、批量、音效时点、透明 VP9 / ProRes；新增 SRT 预览／应用、修改正文／时间／颜色、无效输入禁用保存与渲染、帧定位、云端保存／重载、SRT 导出、手机布局、顶部／底部字幕不遮挡 HUD 图表，以及实际字幕烧录。

编码验证将字幕设置为洋红色，时间 1.010–2.010 秒。实际 720p MP4 下部区域的字幕像素计数为：第 30 帧 0、第 31 帧 3075、第 60 帧 3082、第 61 帧 0。验证字幕按首个可达帧出现，结束时间不包含在显示范围中，预览游标使用相同规则。

保存保护验证 v1 读取不改原文件；v2 保存后，12 条并发保存中 6 条旧 v1 请求被 409 拒绝，6 条 v2 请求成功，字幕保留；无效字幕写入被 422 拒绝，工程字节不变。重启渲染服务后字幕仍可恢复。

并发容量验证同时发出 6 个真实渲染请求，最多接受一条运行加三条排队，其余为 429。写盘错误测试仅将临时测试任务目录设为只读，确认提交失败后任务列表没有伪记录，随后恢复权限并清理测试目录。

## 实片与边界

独立工作台实际生成 15 秒 1080p 三段广告和动态字幕，H.264/AAC。使用本仓库原创合成音乐与三条音效，本次耗时 70.54 秒，平均音量 -28.2 dB、峰值 -6.0 dB。完整解码无报错，卡片／HUD／片尾关键帧已经查看；图表标签与字幕互不遮挡。样片和可导入工程见[字幕功能说明](CAPTIONS.md)。

Remotion Studio 在本机 43148 启动，并用真实 Chromium 打开 `NexusAd` 组合、确认视频画面加载；这不是公网操作地址。

安装器增加构建后可用磁盘检查，并改为逐个构建 API、Web、渲染器，减少共享服务器构建阶段的并发峰值。CPU／内存限制及实例、数据卷、端口所有权保护继续保留。目标腾讯云的安装、网络、实际域名和其他业务健康仍需在该服务器验收。

本次 Docker 实测曾因开发环境的 `vfs` 驱动复制镜像／容器文件耗尽磁盘，渲染器创建任务目录得到 ENOSPC，入口为 503。仅清理明确属于本项目的旧 Web／渲染构建缓存及被替换的测试镜像后重试；没有全局 prune 或清理其他业务。安装器据此为 `vfs` 增加至少 20 GiB 可用空间检查，其他驱动仍至少 5 GiB；构建后至少保留 1.2 GiB 才通过公网发布前验收。

清理后以同一组 API / Web / 渲染镜像和原来的 CPU／内存限制重试通过。容器导出的字幕用 FFmpeg 解码，洋红字幕像素大于 400；音轨 PCM 峰值大于 300。没有删除或停用其他业务容器，测试只删除自身唯一项目的容器和卷。4 项安装器检查也通过，含 vfs 磁盘预算、固定包校验、重试／本地修改保护和私有自动凭据。

语音识别、AI 图片拆解、自动技能编排、一键复刻、通用对象／相机多轨关键帧仍未接入。第二个超限参考片没有读取，不将该文件的全部效果标记为完成。用户参考片与派生截图／OCR 未发布，新增样片均为原创合成素材。
