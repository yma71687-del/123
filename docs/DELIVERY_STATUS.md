## 部署事实

用户腾讯云 110.40.129.161 的控制台截图显示 **0.5.3** 四项服务运行，以及真实 720p 动画、字幕和 AAC 制作验收通过；其公网发布被旧保护检查中止。安装器 0.5.3.2 已修复自有服务重建被误报的风险，并提供 `--resume`。当前会话没有服务器远程执行连接，未核验该服务器其他业务的健康，也没有成功的公网网址。

新界面 **0.5.4** 尚未部署到该服务器。其安装器使用新目录 `~/.local/share/nexus-advertising-v054`、项目 `nexus-ad-v054` 和本机端口 `43154`，不覆盖旧实例，不自动迁移工程和素材。两版同时运行增加资源占用，启动前仍须满足资源检查。旧版恢复命令不会更新到新界面。

单文件试用在精确 ZIP 的 HTML 上以静态宿主加载后断网测试；当前执行环境禁止 file:// 导航，不能把结果称为已在用户 Windows 上直接双击验收。其持久化依赖浏览器本地存储，请保留原素材和工程备份。
