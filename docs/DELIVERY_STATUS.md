# 当前交付入口 · 0.5.3

本版将安装、制作验收、操作示范和源码包合并为一条流程。应用代码和本机容器链路已经实际运行；腾讯云 110.40.129.161 仍未取得可操作的登录连接，未完成该服务器的部署和公网验收。

## 上线流程

使用[腾讯云控制台部署命令](../deploy/ADVERTISING.md)，或在腾讯云终端解压交付 ZIP 后执行根目录的 `bash 部署到腾讯云.sh`。启动器固定版本标签、校验安装器，安装器再校验源码包；自动生成并复用网页密码，无需手动设置密码。

安装会依次完成：

1. 核对目录、Docker 项目、端口、资源和已有容器；创建独立实例，不改其他业务入口。
2. 按顺序构建并启动 API、Web、渲染器和登录网关。
3. 自动提交一个独立的 4 秒 720p 验收任务，只用原创合成素材，不保存或覆盖当前广告工程。
4. 在原有 256 MB / 0.5 CPU 的 API 容器中下载并解码实际输出，核对 H.264/AAC、尺寸、时长、有效声音、字幕时点和真实画面变化。无声视频、静态画面、缺少字幕都不能通过。
5. 通过登录入口下载同一文件并核对 SHA256；公网 HTTPS 入口也需通过同样下载校验，之后才输出成功网址。

重试时复用记录中的验收任务并重新校验文件，不重复创建成功任务，不修改用户保存的工程。`acceptance.json` 保存任务编号、媒体参数、像素／声音数据和校验和，不包含登录密码。

## 打开后直接试用

进入实际网址的 `/#advertising`，点击顶部“载入带声字幕示范”。内置 15 秒工程包含卡片云、HUD 图表、科技片尾、三段字幕、音乐和独立音效；参数与已经交付的 1080p 样片一致。

点击播放试听和预览，修改参数后可保存或真正渲染。“恢复载入前参数”可恢复最近一次载入前的项目和输出设置；浏览器允许存储时，备份也能在刷新后恢复。载入示范本身不写云端工程。
