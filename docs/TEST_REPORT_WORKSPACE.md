## 独立操作界面

`deliverables/NEXUS-AD-WORKSPACE-0.5.4-interactive.zip` 包含 HTML、说明和公开依赖许可。公共下载已返回 HTTP 200，并与发布校验记录匹配；重新构建字节一致。

测试加载精确 ZIP 的 HTML 后断网：文案／字幕可编辑；导入产品图后以 blob 读取；内置配乐及自有音频经原生播放／解码链路输出实际非零声音；IndexedDB 保存后关闭并重开浏览器恢复；JSON 实际下载。记录实际 AudioBufferSourceNode 启动或 HTMLAudioElement 播放状态，未替换音频解码结果。存储被阻止时明确报错，不能显示保存成功。交互期间无 HTTP／WebSocket 依赖。

云端视频导出在本机试用中禁用，参考解析显示服务未连接；没有本机伪任务、伪进度或伪视频下载。当前执行环境禁止 file:// 导航，因此通过静态宿主加载原 HTML 再断网，未直接验证用户 Windows 的文件权限与浏览器策略。

原基础 3D 离线 ZIP 也继续回归，本批两个试用包能力不同。所有截图及媒体均为原创合成示范／测试内容，不包含用户参考原片、抽帧、OCR 或密码。
