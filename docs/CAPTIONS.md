# 广告字幕轨与时间轴 · 0.5.2

字幕已经接入实际广告预览、云端工程和 Remotion 成片。此批使用官方 `@remotion/captions` 4.0.538 的 `Caption` JSON 格式与 `parseSrt()`；显示和编辑组件由 NEXUS 实现，按工程帧时间计算。

## 使用

在包含 0.5.2 的实际站点打开 `/#advertising`，向下找到“字幕轨与时间轴”。

1. 点击“导入 SRT／VTT”，选择 UTF-8 字幕文件。导入预览显示正文、时间、截短与跳过数量，确认后点击“应用这批字幕”。此操作替换字幕轨，画面、音乐和音效保留；“撤回上次导入”恢复导入前整条字幕轨。
2. 如果参考字幕较长，先填“参考字幕起点”，再重新预览导入。例如起点 60 秒、广告长 15 秒，会将源字幕的 60–75 秒映射到广告 0–15 秒。窗口外字幕不会导入，跨边界字幕会截短，结果会显示出来。
3. 可手动添加字幕，逐条修改开始／结束时间和文字，删除字幕。添加会寻找当前游标后的空档。缩短广告后若字幕越界，可明确点击“裁到工程时长”，查看截短／移除数量。
4. 可选择清晰描影、科技面板、弹入强调三种样式、顶部／底部位置、字号上限及颜色。长字幕会折行或缩小至最多三行；画面内容按全轨最大字幕高度预留稳定空间，避免遮住 HUD 图表。
5. 时间轴显示字幕、背景音乐状态与独立音效。点击字幕或音效定位真实播放器，拖动游标预览，播放时游标同步更新；字幕的时间与声音使用同一个工程时钟。
6. 点击“保存到云端”，刷新后读取同一份字幕。也可导出 SRT，或随完整广告 JSON 导出／导入。字幕启停只影响显示，文字和时间保留。
7. 按原流程输出 MP4／透明 WebM／ProRes，或批量套模板。字幕会真实合成进画面，不依赖播放器外挂字幕；透明输出也会包含启用的字幕图形。

参考片解析若成功提取文字型内嵌字幕，会出现“将内嵌字幕送入广告”。点击后仍需核对范围并应用，避免自动覆盖当前字幕。画面 OCR 的散落文字不作为带时间码字幕导入。

## 限制与保存保护

- 广告仍为 4–30 秒。字幕文件最大 128 KiB、最多 2000 个解析块；落入广告窗口后最多 50 条，每条 80 字、三行，至少持续 0.1 秒。
- 禁止字幕重叠、倒序、越界或空正文。无效状态在编辑器显示原因，并禁止保存、单条／批量渲染；导入失败保留原字幕轨。
- SRT / WebVTT 转换为普通文本。支持常见的时间码、VTT 标识符／注释、基本文字标签；VTT 定位、CSS、字体等原格式样式由广告的字幕样式替代。
- 工程升级为 v2。旧 v1 工程读取时仅在内存中迁移，不重写原文件；保存后为 v2。旧 v1 页面不能覆盖已保存的 v2 工程，并发保存也执行版本检查。损坏工程继续拒绝覆盖。
- 同时最多一条实际渲染、三条排队。并发提交使用同一个容量检查；任务先可靠写盘，再进入队列，写入失败不会创建伪排队记录。
- 此时间轴提供广告字幕、音乐状态和音效定位；任意对象／相机的多轨关键帧、完整视频剪辑、语音识别、AI 拆图与一键复刻仍未实现。
